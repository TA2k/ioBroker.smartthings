Connect your Samsung account

This adapter currently uses a Samsung app callback. It cannot yet finish sign-in automatically inside ioBroker; the steps below guide you through the existing flow. Your callback contains temporary authorization data. Do not share it in screenshots, support tickets, or logs.

  1. Open Samsung sign-in in a new tab and complete authentication.
  2. On a desktop browser, open the developer console (F12 or Option + Command + I). If Samsung shows a blank page or an unregistered samsungconnect:// redirect, copy the complete callback URL from the failed redirect.
  3. Paste the callback URL, or the console line containing it, into the field below. Select Validate and use callback, then save the instance settings.
Browser-specific help (Chrome, Firefox, Safari)

Chrome / Firefox: copy the link address from the failed redirect in the developer console. Do not copy only its visible, truncated portion.

Safari: on the Samsung response page, the existing workaround is to use the developer console: copy(document.body.getAttribute("onload").split("'")[1]). This only works when Samsung returns the expected page structure.

Mobile browsers generally cannot expose the necessary developer tools. Use a desktop browser for this legacy login flow. A true one-click login would require a separately registered SmartThings OAuth application and a callback service.

The callback is processed locally in your browser and is not sent to any external helper service.
